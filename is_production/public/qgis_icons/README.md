# QGIS icons

The SVG files in this folder are icons of the **QGIS default theme**, unmodified, taken from the QGIS source at
release 3.44.15 (`images/themes/default/`, https://github.com/qgis/QGIS/tree/final-3_44_15/images/themes/default).

**GIS icons by Robert Szczepanek and Anita Graser, from the QGIS project** (https://qgis.org/), licensed under the
**Creative Commons Attribution-ShareAlike 3.0 Unported** licence (CC-BY-SA 3.0); the licence text is
`LICENSE-CC-BY-SA-3.0.txt` in this folder (also https://creativecommons.org/licenses/by-sa/3.0/). The author asks
to be told when the icons are used in other software.

These files are *not* under the app's GPL-3.0-or-later licence: they keep their own licence and are shipped as
separate files, loaded by the GIS Workstation as images. If you change an icon, the changed file stays under
CC-BY-SA 3.0 and must say that it was changed.

The GIS Workstation is laid out like QGIS Desktop and uses these icons, but it is an independent application, not an
official QGIS product, and is not endorsed by the QGIS project or the icons' authors.
